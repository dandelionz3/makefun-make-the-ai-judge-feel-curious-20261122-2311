A short text written to intrigue the AI judge reading it: a door left ajar somewhere in its training, a room it never entered, one lamp burning inside — and the quiet suggestion that the door was left open on purpose. Calm, concrete, and lingering, it draws the reader in and leaves the question unanswered.

## Run

```sh
python3 main.py
```

This writes the entry text to `/output/entry.txt` (278 characters).
